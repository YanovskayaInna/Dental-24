# Dental 24 — сайт стоматологии в Näfels (Швейцария)

Статический сайт без сборки: файлы загружаются как есть в webroot хостинга (например, `public_html/`).

## Структура
- `index.html` — немецкая версия (основная), `en/index.html` — английская. CSS и JS встроены в HTML.
- `img/`, `fonts/`, `video/` — должны лежать рядом с `index.html`.
- Иконки и логотипы — в корне (`favicon.*`, `icon-*.png`, `logo*.png`, `og-image.jpg`).
- `README.txt` — инструкция по хостингу (на немецком).

## Правила
- Любую правку текста или вёрстки делать в **обеих** версиях: `index.html` и `en/index.html`.
- Внешние скрипты: Lenis (jsDelivr), lottie-web (cdnjs). Если встраиваешь их локально — обнови раздел 6 в Datenschutz.

## Ещё не сделано (из README)
1. Заменить `https://www.example.ch` на реальный домен (canonical, hreflang, og:url, og:image, twitter:image).
2. Форма → Google-таблица: вписать URL Apps Script в `var SHEET_URL=''` в обоих файлах.
3. Impressum/Datenschutz: дописать данные владельца, UID, разрешение, хостинг-провайдера.
4. Аналитика (по желанию): плейсхолдеры `<!-- GA4 -->` и `<!-- Meta Pixel -->` в `<head>`.
